# WordlePlus

A Wordle-inspired game built with Python and Pygame.

## Requirements

- Python 3
- Pygame

Install the required Python package:

```bash
python3 -m pip install pygame
```

## Run program

```bash
python3 src/main.py
```

## Repository

```text
WordlePlus/
├── doc/
├── src/
│   ├── end_screens.py  # End screens
│   ├── game_logic.py   # Game rules and states
│   ├── input_handler.py    # Keyboard and event input
│   ├── main.py         # Entry point and main loop
│   ├── ui.py           # Interface

│   └── word_manager.py # Word manager
```
